# Calculator

A simple calculator built using HTML, CSS, and JavaScript for The Odin Project.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Keyboard support
- Backspace
- Clear button
- Division by zero protection
- Chained operations
- Rounded decimal output

## Technologies

- HTML
- CSS
- JavaScript
